Quickstart

Option A — Setup (Windows): download MtriniWorkspace-Setup-0.6.1.exe from releases and run it.

Option B — source:

pip install -r backend/requirements.txt
npm install --prefix frontend
python -m uvicorn mtrini.main:app --app-dir backend --port 8787
npm run dev --prefix frontend   # http://localhost:5173

Pick a working folder, configure a provider in Settings, start a thread.

Providers

Settings → Providers covers 24 backends: local servers, Ollama, LM Studio, OpenAI, Anthropic, Gemini, OpenRouter, Mistral, DeepSeek, Groq, Together, Fireworks, xAI, Cohere, Cerebras, DeepInfra, Nebius, SambaNova, Novita, SiliconFlow, Azure OpenAI (deployment = model), Hugging Face, SD WebUI and custom OpenAI-compatible endpoints. Keys live in your OS keychain — never in config files.

Local models

  1. Run llama-server -m model.gguf --port 8000, or Ollama / LM Studio.
  2. Settings → Providers → local (or the Ollama/LM Studio preset).
  3. Pick the model in the composer. Check reachability via /api/local/endpoint.

GGUF files can be fetched from Hugging Face inside Models search, one file at a time.

Thinking mode

The composer selector (Off/Low/Medium/High/XHigh/Max) maps to native reasoning controls: OpenAI + Azure reasoning_effort, Anthropic thinking budgets (4K–32K), Gemini thinkingBudget — and deepens the agent tool loop from 12 to 60 steps. Providers without a native control ignore it safely.

Threads & folders

Every chat is a persisted thread with its own working folder (composer folder chip to move it). Rename, delete, and reopen threads from the sidebar; the agent, terminal, Git panel and diff all follow the active thread's folder.

MCP servers

MCP view → Add (stdio command or HTTP URL), enable, Inspect tools, run calls manually. Enabled servers lend mcp__server__tool tools to the agent behind approval. Config is plain JSON (.mtrini/mcp.json) — import/export Claude-shaped files with one click.

Images

Images view → prompt + provider + model + size → Generate. Supported: OpenAI-shape APIs, Gemini native, Hugging Face bytes, SD WebUI, with an OpenAI→SD fallback for local servers. Files land in .mtrini/images/ per folder.

Skills

16 built-in skills (review, debugging, testing, security, performance, SQL, Git…) load into agent context. Add your own as .mtrini/skills/<name>/SKILL.md — project or global (~/.mtrini/skills).

API

Full reference in the repo at docs/API.md: threads, automations, tools, Git, providers, Hugging Face, MCP, images, chat/agent SSE streams. Every route accepts an optional workspace.

FAQ

  • Is it really free? Yes — Apache-2.0. You only ever pay model providers you choose.
  • Does it work offline? Yes with a local model: agent, editor, terminal, Git, skills all run locally.
  • Where are my keys? OS keychain (or a 0600 local fallback). Never in git, logs, or the UI bundle.
  • Which model should I start with? Qwen2.5-Coder via Ollama for code, or any provider's flagship for reasoning.
