Run your coding agent 100% offline with Ollama

October 2026 · 5 min read

Cloud APIs charge per token and see your code. For day-to-day edits, a local coder is free and private. Here's the full path:

  • Install Ollama from ollama.com, then ollama pull qwen2.5-coder (or a 1–3B model for weak hardware).
  • Point Mtrini at it: Settings → Providers → ollama (preset fills http://localhost:11434/v1).
  • Verify: the provider dot goes green; the composer lists your pulled models.
  • Work: open a folder, start a thread, ask for a change. Approve each run until you trust it.

Cost math: a 7B coder on an average laptop does review-size edits in seconds, $0 per month, zero data leaving the machine. Use cloud flagships only for the hardest reasoning — and switch back with one click.
