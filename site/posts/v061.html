Mtrini Workspace 0.6.1: 24 providers, MCP in JSON, Images studio

October 2026 · 4 min read

This release is about choice without lock-in. Mtrini now speaks to 24 model providers through one agent interface — swap Mtrini → Qwen → Gemini → a local GGUF without changing anything else.

MCP went JSON-first. Server config lives in plain .mtrini/mcp.json, import accepts Claude-shaped files, and export produces a file other tools can consume directly. No proprietary registry, no conversion scripts.

Images studio treats picture models like first-class citizens: OpenAI-shape APIs, Gemini native, Hugging Face bytes, SD WebUI — with an honest capability badge per provider instead of fake buttons.

Plus: accent-tinted liquid glass, per-chat folders, thinking effort up to Max, 16 skills. Download the setup and tell us what to build next.
